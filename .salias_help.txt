
UNSLOTH STUDIO SERVICE (UNSLOTH_URL)
  Acts on the "unsloth" Service Dashboard group (:8090), not a single unit --
  services added to the group are picked up automatically.
  unstart           Start every service in the group
  unstop            Stop every service in the group (reverse order)
  unrestart         Restart the group
  unstatus          Show each member's state and start mode
  unlog             Show the last 50 log lines across the group
  unlogf            Follow the group log live

MODEL FARM (hub -> Studio, hard links, no second copy)
  farmplan          Dry run: show what would change, write nothing
  farmsync          Additive sync -- run after importing models into the hub
  rebuildfarm       Destroy the farm and rebuild it -- run after deleting models
                    (a stale hard link keeps the disk space allocated)

AGENTS ON THE LOCAL MODEL
  unclaude          Point Claude Code at this Studio (:8889) and launch it
                    Takes the usual flags: unclaude --model unsloth/Qwen3-4B

GIT (FORK SYNC)
  gitupdate         Fast-forward main from upstream, rebase mryan on top, push both
                    main = verbatim upstream mirror | mryan = your work
